# Limitations

- Domain adapters are reduced-order and illustrative.
- No adapter is calibrated to a named physical facility or commercial device.
- The common detector currently uses transparent heuristic evidence fusion.
- Trust values are scores, not calibrated probabilities.
- The diagnosis logic is intentionally conservative and incomplete.
- Cross-domain threshold transfer is a baseline, not a sophisticated domain-adaptation method.
- One deterministic seed is insufficient for scientific conclusions.
- Real CPS safety certification, standards compliance and operational readiness are out of scope.

# References and Standards Context

This repository should cite primary sources and current reviews in papers rather than treating README claims as evidence.

Useful starting points include:
- NIST publications on security and trust considerations for digital twin technology;
- NIST SP 800-82 Rev. 3 for operational technology security context;
- domain-specific standards and peer-reviewed surveys for each adapter;
- peer-reviewed work on physics-informed CPS anomaly detection, uncertainty quantification, fault diagnosis and domain generalization.

References added to publications must be verified against the original source.

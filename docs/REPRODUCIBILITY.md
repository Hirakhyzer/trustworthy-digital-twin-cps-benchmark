# Reproducibility

Record:
- repository commit SHA;
- Python version;
- operating system;
- domain adapter and version;
- scenario family;
- event start/end;
- magnitude and target;
- random seed;
- residual threshold/calibration method;
- evidence weights;
- uncertainty parameters;
- software changes;
- whether data are synthetic, simulated or measured.

The repository defaults to synthetic simulation data only.

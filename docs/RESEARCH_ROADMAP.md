# Research Roadmap

## v0.2 — rigorous baseline
- multi-seed experiments and confidence intervals;
- full diagnosis confusion matrices;
- uncertainty coverage metrics;
- trust calibration;
- improved rewritten-replay and slow-drift evidence;
- standardized result manifests.

## v0.3 — cross-domain generalization
- leave-one-domain-out feature normalization;
- shared cyber-physical representations;
- domain adaptation baselines;
- unknown-attack evaluation;
- ablation studies.

## v0.4 — higher-fidelity adapters
- adapters that consume outputs from the existing domain repositories;
- explicit adapter contracts and provenance;
- optional measured/public datasets where licensing permits.

## v1.0 — dissertation benchmark release
- frozen benchmark protocol;
- versioned datasets/manifests;
- reproducible paper tables and figures;
- archived release with DOI-ready metadata.
